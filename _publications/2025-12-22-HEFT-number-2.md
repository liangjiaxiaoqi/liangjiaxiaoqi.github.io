RGB-D Salient Object Detection (SOD) is widely used in robot navigation tasks, which helps robots identify and track salient objects in the environment to achieve efficient path planning and obstacle avoidance. However, traditional RGB-D SOD models based on encoder-decoder structures face limitations in extracting high-quality features from different modalities. To solve this dilemma, we propose a Hierarchical Enhanced Fusion Transformer (HEFT) model for RGB-D SOD. This model employs an encoder-converter-decoder architecture to improve the effective fusion and efficient extraction of multimodal information. The core component, the Cross-Modal Cross-Attention Enhanced Transformer Converter (C2E-TC), enables efficient cross-modal competitive learning. Additionally, we designed a Token-based Dual-task Dense Prediction (TDTDP) network, which captures both global and local features to enhance performance in dense prediction tasks. Experimental results demonstrate that HEFT achieves leading performance across several evaluation metrics on benchmark datasets, including NJUD, NLPR, and DUTLF-Depth, validating its effectiveness and superiority in RGB-D SOD tasks.
